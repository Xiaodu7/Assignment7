# Module 7 Reflection

In this module, I learned how to use Docker to run a Python application in a container. Before this assignment, I had heard about Docker, but I didn't really know how to use it.

The most difficult part for me was setting up Docker with Ubuntu. At first, the Docker command was not working because WSL Integration was not enabled. After fixing that, I also had a permission problem. I had to look up the errors and follow some instructions to solve them.

After that, things went more smoothly. I successfully built the Docker image, ran the QR Code Generator, and saved the generated QR code to my local folder. I also learned how to upload an image to DockerHub and use GitHub Actions to automatically build and test the application.

Overall, this assignment helped me understand Docker better, especially how containers make it easier to run applications in different environments.
